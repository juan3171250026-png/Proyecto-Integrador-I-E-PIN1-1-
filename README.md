## Descripción del proyecto

El proyecto consiste en el desarrollo de un sistema de inventario para el negocio
“El Chuy”.

Actualmente, el control de existencias se realiza principalmente de manera manual
y parte de la información se registra en una libreta. Esto dificulta conocer con
precisión qué productos están disponibles, cuáles están próximos a agotarse y qué
mercancía necesita ser reabastecida.

La propuesta consiste en desarrollar un sistema con base de datos que permita
registrar productos, entradas y salidas de mercancía, consultar existencias,
generar alertas de inventario bajo y elaborar reportes sencillos que apoyen la
administración del negocio.
