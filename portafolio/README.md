Proyecto
Sistema de inventario para “El Chuy”

Equipo Dragones
Descripción
Proyecto desarrollado para la asignatura Proyecto Integrador I.

El objetivo es desarrollar un sistema de información que permita llevar un control más ordenado del inventario del negocio “El Chuy”.

El sistema permitirá registrar productos, entradas y salidas de mercancía, consultar existencias, generar alertas cuando un producto tenga pocas unidades y apoyar el proceso de reabastecimiento.
